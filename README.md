# Демо-макет клиентской витрины

**Это дизайн-макет, а не работающий сайт.** Заказы не принимаются, оплата не подключена. Настоящий сайт сети — не этот.

Живая версия: **https://cybercombinat.github.io/hinkalnaya-storefront-demo/**

## Что показывает

Витрина для гостя ресторанной сети: главная, каталог, карточка блюда с модификаторами, корзина с четырьмя типами заказа, статус доставки. Адаптив, работает с телефона.

## Ключевое решение

Меню сети заполнено неравномерно: фотографии есть у 30% позиций, описания у 3%, у категорий картинок нет вообще. Витрина, построенная на фото у каждой позиции, в таких данных превращается в ряды пустых плашек.

Поэтому здесь ведёт типографика: цены выстраиваются моноширинной колонкой как в прайс-листе, а вместо отсутствующего фото — монограмма. Буква берётся не из начала названия, а из самого длинного значимого слова, поэтому различает начинку: Б — баранина, Г — говядина, С — сыр. Строки с фото и без стоят вперемешку и не выглядят сломанными.

## Белолейбл

Все цвета — CSS-переменные. Смена темы арендатора не трогает разметку:

```js
document.documentElement.style.setProperty('--brand', '#123A63');
document.documentElement.style.setProperty('--accent', '#E2603B');
```

## Доступность

Контраст текста проверен арифметически по WCAG, все пары проходят AA. Фокус с клавиатуры заходит в модальное окно, запирается внутри и возвращается на кнопку открытия. Режим «меньше движения» снимает перемещения, но сохраняет отклик на нажатие. Тач-цели на телефоне 44 px.

## Ограничения

Не ходит в API вживую — данные статический слепок. Нет авторизации, оплаты, карты зоны доставки, поиска по меню и сохранения корзины.
